# Ultrahuman Max landing page

Info-only landing page for Ultrahuman Max. Open `lp.html`.

- `lp.src.html` is the source; `python3 -I build_lp.py` builds `lp.html` (the WebGL engine is taken from `agentic.html`).
- `hero.html`, `hero-bh.html`, `jade.html`, `jade-burst.html`, `agentic.html` are standalone shader studies.
- Serve the folder with any static server, e.g. `python3 -m http.server 4190`.
